# Proyecto de instalación informática de un CPD (Grupo 135)

Proyecto en grupo de la ETSIINF-UPM (curso 2024-25) sobre el diseño de la instalación del **Centro de Proceso de Datos** de una empresa de reserva de transporte bajo demanda.
