# Proyecto de instalación informática de un CPD (Grupo 135)

Proyecto en grupo de la ETSIINF-UPM (curso 2024-25; en Teams aparece como PII) sobre el diseño de la instalación del **Centro de Proceso de Datos** de una empresa de reserva de transporte bajo demanda.

## Entregables
- `PLANTILLA5. D2.1 Tabla Equipamiento...xlsx`: tablas de equipamiento (procesamiento, almacenamiento, comunicaciones, potencia).
- `D2.2_Infraestructura`: infraestructura física del CPD.
- `D2.3_SistemaElectrico`: sistema eléctrico y SAI.
- `D2.4_Termotecnia`: climatización.
- `D2.5_CableadoEMIEMC`: cableado estructurado y compatibilidad electromagnética.
- `D3_memoriafinal_g135.pdf`: memoria final.
